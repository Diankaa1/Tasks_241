# Перенаправляем

## 1) Как работают команды >,>>?
Команды перенаправляют вывод команды в то, что указано после символа:

">" — перезаписывает содержимое файла.

">>" — добавляет вывод в конец файла.

Пример:

```bash
echo "PUPUPU" > file.txt 
# Запись в файл

echo " AAAAAAAAAAAAAAAAAAAAAAAAAA" >> file.txt
# Добавление в конец файла
```

## 2) Что такое перенаправление ввода? stderr,stdout;
Перенаправление ввода — процесс изменения источника ввода данных для программы или команды в операционной системе. Используется для передачи данных из файла или другой команды в стандартный ввод команды.

```bash
echo " AAAAAAAAAAAAAAAAAAAAAAAAAA" > file.txt
cat < file.txt
```
- stderr — стандартный поток ошибок. Используется для вывода сообщений об ошибках.

- stdout — стандартный поток вывода. Используется для отображения обычного результата работы команды.

## 3) Вывести содержание файла не используя текстовые редакторы;

Выводит содержимое файла целиком на экран:
```bash
cat file.txt
```


Позволяет просмотреть файл постранично:
```bash
less file.txt
```

Аналогично less, но урезанный функционал:
```bash
more file.txt
```


Выведет первые строки (по умолчанию 10 первых):
```bash
head file.txt
```

Выведет последние строки (по умолчанию 10 последних):
```bash
tail file.txt
```

## 4) Создать файл с содержимым не используя текстовые редактор;

Для этого нужно использовать команду echo, которая создаст файл с содержимым "HELPPPPP" и запишет его в файл.:

```bash
echo "HELPPPPP" > file.txt
```

## 5) Перенаправить stdout в stderr и обратно на примере команды kinit, ping, tracert

- kinit — получение Kerberos-тикета.

- ping — проверка доступности хоста в сети.

- tracert (traceroute) — отслеживание маршрута.

Пример перенаправления:

```bash
ping sait.com
# Стандартный вывод в поток ошибок:
ping sait.com > /dev/stderr

# Стандартный поток ошибок в стандартный вывод:
ping sait.com 2> /dev/stdout
Сохранить ошибки kinit в файл stderr.log.
```

Сохранить ошибки kinit в файл stderr.log.

```bash
kinit 2> stderr.log 
```

## 6) Чем отличаются stdout и stderr

stdout — это поток, куда программа выводит результаты своей работы.

stderr — это поток, куда программа выводит сообщения об ошибках.

## 7) Что такое stdin?

stdin — это поток, из которого программа получает входные данные.

## 8) как отправить весь вывод команды в пустоту?

Дабы отправить весь вывод команды в пустоту мы используем перенаправление в /dev/null:

ping sait.com > /dev/null
