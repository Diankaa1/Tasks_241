# Работа в консольке

## 1) Переместиться между директориями

```bash
cd #путь к директории
```

## 2) Вывести список файлов в директории

```bash
ls              # Вывести список файлов
ls -l           # Подробный список файлов
ls -a           # Показать скрытые файлы
ls -la          # Подробный список со скрытыми файлами
```

## 3) Вывести список Всех файлов в директории

```bash
ls -R
```

## 4) Создать папку с подпапками

```bash
mkdir -p название1/название2/название3
```
 К примеру:
 ```bash
mkdir -p папка_1/папка_2/папка_3
```
В папке_1 будет папка_2, а в папке_2 будет папка_3
## 5) Внутри папки создать файлик и записать в него что-нибудь

```bash
touch имя_файла             # Создать пустой файл
echo "Текст для записи" > file.txt # Записать текст в файл
cat название_файла.txt                       # Прочитать содержимое файла
vim название_файла.txt                       # Редактировать файл с помощью vim
```

## 6) Переместить файл из одно директории в другую

Предположим, что файл в папка_2.
В зависимости от того, в какой директории мы находимся, мы действуем по-разному.
Если мы находимся, к примеру, в папка_1, то указываем путь до файла lala, а после
через пробел указываем путь до папки куда перемещаем.
 Пример:
```bash
mv папка2/lala папка_2/папка_3
```
 Если находимся в папка_2, то забираем файл, а после указываем путь к файлу,
 куда переносим.
```bash
mv lala папка_3
```
Если находимся в директории папка_3, то поднимаемся в директорию вверх(../), 
где забираем файл, а после через пробел ставим точку, которая показывает, что
 мы перемещаем в текущую директорию, где мы находимся.

```bash
mv ../папка_2/lala .
```

## 7) Скопировать файл из одной директории в другую

В зависимости от того, в какой директории мы находимся, мы действуем по-разному.
Если мы находимся, к примеру, в папка_1, то указываем путь до файла lala, а после

## 8) Переименовать файл

```bash
mv старое_имя новое_имя
```
Если мы находимя не в той директории, где у нас файл, то указываем
путь к файлу перед старым и новым названием.

## 9) Сравнить содержимое файла

```bash
diff файл1 файл2 # Сравнить файлы с выводом различий
cmp файл1 файл2  # Побайтовое сравнение файлов
```
Перд файлом один и два можно указать путь, если мы находимся не в
 этой папке, либо файлы находятся в разных папках.
## 10) Отсортировать содержимоей файла по возрастанию и убыванию

```bash
sort файл                  # Сортировка по возрастанию
sort -r файл               # Сортировка по убыванию
sort файл > sortedфайл # Сохранение результата в новый файл
```


## 11) Удалить все папки и файлы

```bash
rm -rf путь/к/директории
# Удаляет папку и всё её содержимое без подтверждения
```
