# Управление пользователями

## 1) Добавьте пользователей user1 и user2:

1.1) user1 - оболочка bash

```bash
useradd -m -s /bin/bash user1
```

1.2) user2 - оболочка sh

```bash
useradd -m -s /bin/sh user2
```

1.3) установите им пароли

```bash
passwd user1
passwd user2
```

1.4) Выведем пользователей в системе


```bash
cat /etc/passwd | tail -n 2 # -n 2 выведет последних двух
```

## 3) Что такое права доступа? Выведите права доступа на файлы в директории пользователя

Права доступа показывают кто (владелец/группа/другие) и что (r-чтение, w-запись, x-выполнение) могут делать с файлом/директориями.

Права доступа можно увидеть, если использовать команду:

```bash
ls -l
```

За права файлов в linux тут отвечают черточки. Первая это тип файла. Дальше же идут группы прав сначала для владельца, для группы и для всех остальных. Всего девять черточек на права и одна на тип.

Что именно значат условные значения флагов прав:

- --- - нет прав, совсем;
- --x - разрешено только выполнение файла, как программы но не изменение и не чтение;
- -w- - разрешена только запись и изменение файла;
- -wx - разрешено изменение и выполнение, но в случае с каталогом, вы не можете посмотреть его содержимое;
- r-- - права только на чтение;
- r-x - только чтение и выполнение, без права на запись;
- rw- - права на чтение и запись, но без выполнения;
- rwx - все права;
- --s - установлен SUID или SGID бит, первый отображается в поле для владельца, второй для группы;
- --t - установлен sticky-bit, а значит пользователи не могут удалить этот файл.

## 4) Как изменить права на файлы? Создайте файл который будет на который у всех пользователей будут все возможные права

Существует два способа для изменения прав, которые используются с командой chmod.

### 1 ) Восьмиричный способ.

Каждому праву соответствует число:
- r: 4
- w: 2
- x: 1

Права для каждой категории (владелец, группа, остальные) задаются суммой соответствующих чисел.

### 2 ) Символьный. 

Необходимо просто написать кому и какие права вы хотите присвоить(+)/забрать(-)/установить(=). Если всем, то пишем a - all.


#### Создаем файл, на который у всех пользователей будут все возможные права:

- Восьмиричный способ:

```bash
chmod 777 file.txt
```

## 5) Как называется учётная запись встренного администратора в linux?

Она называется root. У рута есть полный доступ на все.

## 6) Как выполнить команду от имени администратора?

```bash
sudo "команда"
```

## 7) Есть ли ограничения у суперпользователя?

Из ограничений - системные и настройки безопасности. Особо больше информации не нашла.

## 9) Как можно изменить владельца папки? Измените владельца папки из пункта 4

Это можно сделать с помощью команды chown.

