# ФС

1) Какие файловые системы вы знаете?

Хорошо, вот краткий список наиболее распространенных файловых систем:

- FAT (File Allocation Table) — старая, простая файловая система, часто используется на флешках. Ограничение размера файла 4 ГБ (FAT32).

- NTFS (New Technology File System) — основная файловая система Windows. Поддерживает права доступа, шифрование и журналирование.

- ext2 (Second Extended File System) — одна из первых файловых систем Linux. Не поддерживает журналирование.

- ext3 (Third Extended File System) — журналируемая версия ext2, повышает устойчивость к сбоям.

- ext4 (Fourth Extended File System) — самая распространенная файловая система Linux. Быстрая, надежная, поддерживает большие файлы.

- Btrfs (B-tree file system) — современная файловая система Linux со снимками, сжатием и RAID.

- XFS — высокопроизводительная файловая система Linux для больших файлов и хранилищ.

- exFAT (Extended File Allocation Table) — используется на флешках и внешних дисках, поддерживает файлы больше 4 ГБ.

- HFS+ (Hierarchical File System Plus) — использовалась в macOS до High Sierra.

- APFS (Apple File System) — современная файловая система macOS, iOS, iPadOS и др. Оптимизирована для SSD.

- ZFS (Zettabyte File System) — мощная файловая система с RAID, сжатием и дедупликацией. Используется на серверах.

- UFS (Unix File System) — используется в BSD-системах.

2) Как можно классифиировать файловые системы? в чём отличия??

По типу носителя: дисковые (HDD, SSD), оптические (CD, DVD), флеш-память, сетевые, виртуальные.

По организации данных: простые, иерархические, объектно-ориентированные.
По наличию журнала (журналирование): журналируемые (с журналом, более надежные), нежурналируемые.

По типу доступа: локальные, удаленные (сетевые).

3) Какие файловые системы используются в linux?

В Linux используется множество файловых систем, но наиболее распространены следующие:

ext2: Старая, простая, без журналирования (редко используется сейчас).
ext3: Журналируемая версия ext2 (практически вытеснена ext4).
ext4: Самая популярная, быстрая, надежная, с журналированием.
XFS: Для больших файлов и хранилищ, высокая производительность.
Btrfs: Современная, со снимками, сжатием и RAID.
ZFS: Мощная, для серверов, с RAID, сжатием и дедупликацией.
Также поддерживаются для совместимости:

FAT32/exFAT: Для флешек и внешних дисков.
NTFS: Для работы с разделами Windows.

4) Как можно создать файловую систему на диске?

Для этого необходимо использовать команду mkfs.

К примеру, для создания файловой системы ext4 на диске /dev/sdb1:

```bash
sudo mkfs.ext4 /dev/sdb1
```

5) Как можно подключить диск в систему, что такое монтирование?

Монтирование — это связывание файловой системы на диске с определённым каталогом (точкой монтирования).

Чтобы подключить (смонтировать) диск в систему, используется команда mount.

```bash
sudo mount /dev/sdb1 /mnt
```

где /mnt — точка монтирования (каталог, где будет доступна файловая система).

Для автоматического монтирования при старте системы обычно используется файл /etc/fstab.
