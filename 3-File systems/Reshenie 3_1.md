# ФС

## 1) Какие файловые системы вы знаете?

FAT, NTFS, ext2, ext3, ext4, Btrfs, XFS, exFAT, HFS+, APFS, ZFS, UFS.

## 2) Как можно классифиировать файловые системы? в чём отличия??

По типу носителя: дисковые (HDD, SSD), оптические (CD, DVD), флеш-память, сетевые, виртуальные.

По организации данных: простые, иерархические, объектно-ориентированные.

По наличию журнала (журналирование): журналируемые (с журналом, более надежные), нежурналируемые.

По типу доступа: локальные, удаленные (сетевые).

## 3) Какие файловые системы используются в linux?

В Linux используется множество файловых систем, но наиболее распространены:

ext2, ext3, ext4, XFS, Btrfs, ZFS, FAT32, exFAT, NTFS, HFS+, APFS, UFS

## 4) Как можно создать файловую систему на диске?

Для этого необходимо использовать команду mkfs.

К примеру, для создания файловой системы ext4 на диске /dev/sdb1:

```bash
sudo mkfs.ext4 /dev/sdb1
```

## 5) Как можно подключить диск в систему, что такое монтирование?

Монтирование — это связывание файловой системы на диске с определённым каталогом (точкой монтирования).

Чтобы подключить (смонтировать) диск в систему, используется команда mount.

```bash
sudo mount /dev/sdb1 /mnt
```

где /mnt — точка монтирования (каталог, где будет доступна файловая система).

Для автоматического монтирования при старте системы обычно используется файл /etc/fstab.

## 6) файловая система procfs, cifs, tpmfs,sysfs. В чём особенности каждой из них?

*procfs* — виртуальная файловая система, которая предоставляет информацию о текущем состоянии операционной системы и процессах. Она монтируется в каталог /proc:

```bash
ls /proc
```

*cifs* — файловая система, которая используется для подключения к удаленным папкам по протоколу SMB/CIFS (чаще всего используется для работы с общими папками Windows).

*Tmpfs* — это временная файловая система, предназначенная для хранения файлов в виртуальной памяти.

```bash
ls /sys/class/tpm
```

*sysfs* — виртуальная файловая система, предоставляющая информацию о текущем состоянии ядра и устройствах. Она монтируется в каталог /sys:

```bash
ls /sys
```


## 7) Как можно получить информацию о системе используя лишь команду cat?
Необходимо использовать cat + каталог /proc, который является виртуальной файловой системой, предоставляющей информацию о текущем состоянии системы.

- Информация о процессоре:

```bash
cat /proc/cpuinfo
```

- Информация о памяти:

```bash
cat /proc/meminfo
```
